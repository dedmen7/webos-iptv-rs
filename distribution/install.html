Install on an LG TV

This package targets LG webOS 5.0 and later. Model, region, and stream compatibility can vary. Download the .ipk from GitHub Releases.

  1. On your TV, install Developer Mode from LG Apps. Sign in with an LG Developer account, turn Developer Mode on, and let the TV restart.
  2. Open Developer Mode again and turn on Key Server. Have the TV's IP address and the temporary passphrase from that screen ready.
  3. On a computer connected to the same network, install webOS Dev Manager. Add your TV using the IP address and passphrase shown on the TV.
  4. Select the TV in Dev Manager, choose the option to install from a file, and select the Orbis .ipk. Open Orbis IPTV from the TV's Home screen.
  5. Choose Xtream account or M3U link. Enter the details provided by your IPTV provider and select Save.

Orbis is a player. Bring your own playlist or subscription. It stores the source on your TV and connects directly to the provider. Developer Mode has a time limit. Select Extend before it expires. LG removes test apps when Developer Mode is disabled. LG Developer Mode instructions

Installeren op een LG-tv

Dit pakket is bedoeld voor LG webOS 5.0 of hoger. Ondersteuning kan per model, regio en stream verschillen. Download het .ipk-bestand bij GitHub Releases.

  1. Installeer Developer Mode via LG Apps op je tv. Log in met een LG Developer-account, zet Developer Mode aan en laat de tv opnieuw opstarten.
  2. Open Developer Mode opnieuw en zet Key Server aan. Houd het IP-adres en de tijdelijke passphrase op dat scherm bij de hand.
  3. Installeer webOS Dev Manager op een computer op hetzelfde netwerk. Voeg de tv toe met het IP-adres en de passphrase op je tv.
  4. Selecteer de tv in Dev Manager, kies installeren vanuit een bestand en selecteer het .ipk-bestand van Orbis. Open Orbis IPTV vanuit het LG-startscherm.
  5. Kies Xtream-account of M3U-link. Vul de gegevens van je eigen IPTV-aanbieder in en kies Opslaan.

Orbis is een speler voor je eigen afspeellijst of abonnement. De bron wordt op je tv opgeslagen en Orbis maakt rechtstreeks verbinding met je aanbieder. Developer Mode heeft een tijdslimiet. Kies op tijd Extend. LG verwijdert testapps wanneer Developer Mode wordt uitgeschakeld. LG-handleiding voor Developer Mode

Auf einem LG-Fernseher installieren

Das Paket ist für LG webOS ab Version 5.0 vorgesehen. Die Unterstützung kann je nach Modell, Region und Stream variieren. Lade die .ipk-Datei unter GitHub Releases herunter.

  1. Installiere Developer Mode über LG Apps. Melde dich mit einem LG-Entwicklerkonto an, aktiviere den Entwicklermodus und starte den Fernseher neu.
  2. Öffne Developer Mode erneut und aktiviere Key Server. Halte die IP-Adresse und das vorübergehende Kennwort auf diesem Bildschirm bereit.
  3. Installiere webOS Dev Manager auf einem Computer im selben Netzwerk und füge den Fernseher mit der angezeigten IP-Adresse und dem Kennwort hinzu.
  4. Wähle den Fernseher in Dev Manager aus, installiere die Orbis-Datei mit der Endung .ipk und öffne Orbis IPTV auf dem Startbildschirm.
  5. Wähle Xtream-Konto oder M3U-Link. Gib die Daten deines IPTV-Anbieters ein und wähle Speichern.

Orbis spielt deine eigene Wiedergabeliste oder dein Abo ab. Die Quelle bleibt auf dem Fernseher und Orbis verbindet sich direkt mit deinem Anbieter. Der Entwicklermodus ist zeitlich begrenzt. Wähle rechtzeitig Extend. LG entfernt Test-Apps, wenn der Entwicklermodus deaktiviert wird. Anleitung von LG

Installer Orbis sur un téléviseur LG

Ce paquet est prévu pour LG webOS 5.0 ou version ultérieure. La compatibilité dépend du modèle, de la région et du flux. Téléchargez le fichier .ipk depuis GitHub Releases.

  1. Installez Developer Mode depuis LG Apps. Connectez-vous avec un compte développeur LG, activez le mode développeur et laissez le téléviseur redémarrer.
  2. Rouvrez Developer Mode et activez Key Server. Relevez l’adresse IP et la phrase secrète temporaire affichées sur cet écran.
  3. Installez webOS Dev Manager sur un ordinateur connecté au même réseau. Ajoutez le téléviseur avec les informations affichées à l’écran.
  4. Sélectionnez le téléviseur dans Dev Manager et installez le fichier Orbis .ipk. Ouvrez Orbis IPTV depuis l’écran d’accueil.
  5. Choisissez Compte Xtream ou Lien M3U. Saisissez les informations de votre fournisseur IPTV, puis sélectionnez Enregistrer.

Orbis lit votre liste ou abonnement IPTV. La source est enregistrée sur votre téléviseur et Orbis se connecte directement à votre fournisseur. Le mode développeur est limité dans le temps. Choisissez Extend avant son expiration. LG supprime les applications de test lorsque le mode développeur est désactivé. Mode d’emploi de LG
